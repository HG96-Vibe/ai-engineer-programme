Curriculum

From Beginner to Career-Ready in Three Phases

Every stage is hands-on — you learn by building, not by watching. Recorded lectures, notes and a quiz for each topic, then a guided build with a defined finish line. Work through it at your own pace with a trainer available whenever you need one.

Build the way you think about AI before any code appears

You learn what AI actually is, how a language model answers a question, why it makes things up, and what the job really involves. Then you build a complete AI assistant with no code at all, so retrieval, tool use, evaluation and deployment are familiar before you write Python.

Stage 0

What AI is and what an AI engineer does

AI, ML and LLMs; tokens, context windows, embeddings; the model landscape; the job as UK adverts describe it.

You build: your own explainer of how an LLM answers a question
Stage 1

The whole workflow, no code (Copilot Studio)

Build an assistant, add knowledge sources, add actions, test it, publish it to Teams — and be told which later stage each button maps to.

You build: an internal policy assistant, published to Teams
Stage 2

Python for AI engineering

Application Python: functions, classes, JSON, error handling, HTTP APIs, Git and a first test. Written by you, not by an AI assistant.

You build: a command-line tool with tests, on GitHub

Quizzes after every chapter on the portal. You learn why each stage exists before you start it.

Rebuild the Stage 1 assistant in code, then make it production-grade

Stages 3 to 8 extend the same application rather than starting ten separate exercises. You finish with one real system you can explain end to end in an interview — the two build patterns every portfolio needs, plus the evaluation and deployment skills that separate a demo from a product.

Stage 3

Working with LLM APIs

Call a model from Python; system prompts, structured outputs, streaming, cost and latency; wrap it in a FastAPI service.

You build: a chat service that runs on two model providers
Stage 4

Context engineering

Prompts, examples, output schemas, tool descriptions, token budgeting, and defending against prompt injection.

You build: validated structured outputs and injection defences
Stage 5

Retrieval-augmented generation (RAG)

Chunking, embeddings, vector stores, hybrid search, reranking, citing sources, measuring retrieval quality. In about half of UK adverts.

You build: document Q&A with cited answers and a quality score
Stage 6

Agents and tool use

Function calling, an agent loop from scratch, then a framework; MCP servers; guardrails and safe fallbacks.

You build: an agent that calls real tools and fails safely
Stage 7

Evaluation

Test sets, model-as-judge, human review, regression tests for prompts, tracing. The skill almost every course skips.

You build: an evaluation suite and a report of what your agent gets wrong
Stage 8

Shipping to production

Docker, one cloud, CI/CD that blocks deployment if evaluations regress, logging, monitoring, auth, cost per request.

You build: your agent live at a public URL with a pipeline

AI-assisted development is introduced in Stage 3 as a working practice, with one rule: you must be able to explain every line.

Solve a real business problem end to end, then go and get hired

The capstone is the credential: a public repository, a live deployment, an evaluation report and a recorded ten-minute presentation to a business audience. Then the honest bit — which titles to search, how to spot a paid course dressed up as a vacancy, and how to write a CV in the words employers use.

Stage 9

Capstone

You build: your portfolio — repo, live app, eval report, presentation
Stage 10

Getting hired

Which titles to search, spotting fake vacancies, a CV in employer vocabulary, the Microsoft-stack route into regional employers, interview practice, progression.

FAQs

Questions People Ask Before Joining

Do I need a degree or any experience in tech?

No. The programme starts with theory told as a story and a complete no-code workflow before any Python appears. Many junior AI adverts do ask for a degree, and we say so plainly — the programme's answer is a portfolio strong enough to be considered without one.

Will I learn to train my own AI models?

No, and that is deliberate. None of the UK adverts we analysed were about training models from scratch. You learn to understand models well enough to choose, use, constrain and evaluate them, which is what the job actually involves.

Why start with a no-code tool instead of Python?

Because understanding the shape of the job is more important than syntax. In Stage 1 you build a full AI assistant without code and are told, as you go, which later stage each button corresponds to. When Python arrives, you already know what you're building and why.

How long does it take?

It depends on the hours you can give it. Self-paced, most people should expect several months of consistent part-time study. We'll publish clearer guidance with the enrolment details once the full programme has been through its first learners.

What does it cost?

Pricing will be announced when enrolment opens. People on the waitlist will be told first and offered early-cohort pricing.

Do you guarantee a job?

No. Anyone who guarantees a job in this market is not being honest with you. We teach the capability, you build the portfolio, and our recruitment support gives you a realistic search plan, a rewritten CV and interview practice.
